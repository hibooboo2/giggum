This folder implements a Ralph Wiggum autonomous AI coding loop. It contains:

- **ralph.sh**: A bash script that runs AI coding CLI in autonomous loops
- **prompt.md**: Instructions for the AI to follow on each iteration  
- **tasks.md**: The task list being worked on (this file)
- **progress.txt**: Tracks progress between iterations
- **wiggum.md**: Documentation about Ralph Wiggum methodology

The Ralph pattern lets AI agents work autonomously by choosing their own tasks from a list, implementing them with feedback loops (tests, types, linting), committing code, and tracking progress until all tasks are complete.
